Assignment-8:
Online shopping and service platforms often contain fake or misleading reviews. Develop a machine-learning system to classify reviews as genuine or fake. First, build a model using only the review text. Then incorporate additional simple information such as star rating, review length, sentiment score, or rating–sentiment mismatch. Investigate whether these additional features actually improve fake-review detection.
For example, a review saying “Excellent product, highly recommended” but giving 1 star may contain useful inconsistency information.
Compare: Text-only model vs Text + Metadata model.
Metrics: Accuracy, Precision, Recall, Macro-F1, MCC
